# Starbucks Landing Page - Mobile First

Este é um projeto de estudo baseado no vídeo do YouTube disponível no link: [Como fazer uma Landing Page com HTML, CSS e JavaScript | Mobile First](https://www.youtube.com/watch?v=ik-njdH5Q5c), do canal da Larissa Kich.

## Descrição

O objetivo deste projeto é criar uma landing page responsiva para a Starbucks, utilizando o conceito de Mobile First. O design e a estrutura foram desenvolvidos com foco em dispositivos móveis, garantindo uma experiência de usuário otimizada em telas menores antes de adaptar para telas maiores.

## Estrutura do Projeto

A estrutura do projeto é organizada da seguinte forma:

```
index.html
src/
  css/
    about.css
    colors.css
    font.css
    footer.css
    global.css
    home.css
    main.css
    navbar.css
    products.css
    trending.css
  images/
    about/
    products/
    trending/
  js/
    script.js
```

- **HTML**: Contém a estrutura principal da página.
- **CSS**: Arquivos de estilo organizados por seções e funcionalidades.
- **JS**: Contém scripts para interatividade.
- **Imagens**: Diretórios organizados para diferentes seções da página.

## Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**

## Como Visualizar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/adrianojrvidal/starbucks-landingpage-mobilefirst.git
   ```
2. Navegue até o diretório do projeto:
   ```bash
   cd starbucks-landingpage-mobilefirst
   ```
3. Abra o arquivo `index.html` em seu navegador.
